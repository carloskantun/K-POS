## Cargar y administrar

- Negocio nuevo: Crear mi negocio → Rock Alitas · Menú real.
- Negocio existente: si aún no usa la plantilla, elegir el giro Rock Alitas · Menú real en Ajustes → Negocio y guardar. Luego Ajustes → Menú Rock Alitas → Cargar productos faltantes. Confirma el nombre del negocio antes de cargar.
- Si el negocio existente no usa comandas o mesas, activa esas funciones en Ajustes → Negocio antes de operar el restaurante.
- En el panel, toca un producto cargado para cambiar precio, foto, categoría, estación, estado, extras o receta.
- Las órdenes, paquetes y productos aparecen en Vender. Las opciones elegidas se incluyen en comandas y tickets.
- La carga no modifica productos existentes, no borra ejemplos y no restaura productos eliminados. Los productos originales de ejemplo pueden desactivarse en Ajustes → Productos.
- El CSV permite revisar precios e importar datos básicos; no transporta las variantes. Para cargar las salsas usa el panel o el perfil Rock Alitas.

## Configuración para revisar

Cocina/barra es una asignación operativa inicial. Cada producto es una unidad vendida (orden, paquete, botella o bebida), no un litro facturado a granel. Costos, existencias y recetas requieren captura: costo 0 es el valor inicial técnico, no un costo real. No usar márgenes de estos productos hasta registrar costos. El perfil usa 12 mesas de ejemplo, sin asumir el número real del local.

Las salsas se configuran inicialmente con una selección obligatoria, sin cargo adicional. El límite real por orden no figura en las fotos; ajustarlo con el encargado. Rock & Cheese se etiqueta para fines de semana, pero su disponibilidad no se bloquea automáticamente. Las opciones de carne y guarniciones parten de las descripciones impresas; validar con cocina. No se inventan marcas de cerveza ni sabores de refresco.
